# Melhora a Tua Letra ✍️✨

Uma aplicação web interativa e gamificada, fortemente inspirada no **Duolingo**, desenvolvida para ajudar utilizadores de tablets, telemóveis e computadores a aperfeiçoar a sua caligrafia de forma divertida e autónoma.

## 🚀 Funcionalidades

- **Treino Inteligente (IA Geométrica):** O utilizador desenha diretamente no ecrã (com o dedo ou caneta/Apple Pencil) por cima de letras guia. O algoritmo analisa a estabilidade e a precisão do traço em tempo real.
- **Sistema de Recompensas:** Acumulação de cristais (moedas virtuais) e contagem de dias seguidos (ofensiva) ao atingir pontuações elevadas (+75% de precisão).
- **Interface Gamificada:** Mudança dinâmica de cores de feedback (verde para traços corretos, vermelho para desvios fora da margem).
- **Impressão de Pauta Escolar:** Um botão que gera automaticamente um caderno de linhas pontilhadas limpo com a letra selecionada, otimizado para qualquer impressora via AirPrint ou navegador.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura semântica e estilização moderna com variáveis nativas e design responsivo.
- **JavaScript (Vanilla):** Motor lógico de desenho em elementos `<canvas>`, manipulação de eventos táteis e algoritmo geométrico de precisão.

## 🎮 Como Jogar / Executar

1. Abre a aplicação no teu tablet ou telemóvel.
2. No menu principal, clica em **"1. Treinar no Ecrã (IA)"**.
3. Desenha a letra indicada o mais próximo possível do guia cinzento.
4. Solta o dedo/caneta para veres a tua avaliação da IA e ganhares cristais.
5. Se preferires treinar no papel, clica em **"Imprimir Pauta Escolar"** para mandares o exercício diretamente para a tua impressora.
